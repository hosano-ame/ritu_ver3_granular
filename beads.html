LFO の ● を、つまみの ◎ へドラッグしてつなぎます。プラグをクリックすると深さ、外へドラッグすると外れます。変調は「グレインが鳴り始めた瞬間」の値に効きます。

Mutable Instruments とは関係がなく、承認も受けていない非公式の移植です。ヘッドホンを使うときは、端末の音量を小さくしてから再生してください。

ソースコードとの対応（学習用メモ）
  • GrainEnvelope ← beads/dsp/grain_envelope.h：SHAPE からアタック/サステイン/リリースとスムーズネスを計算
  • VoiceStealingEnvelope ← beads/dsp/voice_stealing_envelope.h：32 ボイスを使い切ったときの短いフェードアウト
  • SampleGrain ← beads/dsp/delay_grain.h：Hermite 補間で読み出し、端に近づくとフェード、端を越えたら停止（HEAD_CROSSING_POLICY_STOP）
  • GranularPlayer ← beads/dsp/granular_player.h + delay_granular_player.h：グレイン長の計算、音量 1/√N、パンの広がり、ボイススチールの優先順位付け
  • BeadsEngine.nextTrigger ← beads/dsp/trigger_generator.cc の RenderPulseTrain：位相累積でトリガー、サンプル以下の端数（fractional_sample）も保持
  • ModCore ← nami-synth/index.html の ModCore：LFO×2。1 サンプル前の出力をケーブルの深さで足し合わせ、行き先ごとの変調量を作る（Beads 原機にはない追加機能）

原機との違い：外部入力の録音バッファの代わりに WAV を「FREEZE が常にオン」の状態として扱います。TIME は原機では「書き込みヘッドから遡る量」ですが、ここでは「ファイル先頭からの位置」です。原機の TIME/SIZE/SHAPE/PITCH にあるランダム量（アッテネーター）は省き、代わりに LFO で動かします。固定小数点（×1024）は浮動小数点に置き換えています。フィードバック、リバーブ、低ビットの音質モードは未実装です。
