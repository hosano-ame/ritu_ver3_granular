ソースコードとの対応（学習用メモ）
  • GrainEnvelope ← beads/dsp/grain_envelope.h：SHAPE からアタック/サステイン/リリースとスムーズネスを計算
  • VoiceStealingEnvelope ← beads/dsp/voice_stealing_envelope.h：32 ボイスを使い切ったときの短いフェードアウト
  • SampleGrain ← beads/dsp/delay_grain.h：Hermite 補間で読み出し、端に近づくとフェード、端を越えたら停止（HEAD_CROSSING_POLICY_STOP）
  • GranularPlayer ← beads/dsp/granular_player.h + delay_granular_player.h：グレイン長の計算、音量 1/√N、パンの広がり、ボイススチールの優先順位付け
  • RandomizedParameter ← beads/dsp/randomized_parameter.h：CV 未接続時のアッテネーターの挙動
  • TriggerGenerator ← beads/dsp/trigger_generator.cc の RenderPulseTrain：位相累積でトリガー、サンプル以下の端数（fractional_sample）も保持

原機との違い：外部入力の録音バッファの代わりに WAV を「FREEZE が常にオン」の状態として扱います。TIME は原機では「書き込みヘッドから遡る量」ですが、ここでは「ファイル先頭からの位置」です。固定小数点（×1024）は浮動小数点に置き換えています。フィードバック、リバーブ、低ビットの音質モードは未実装です。

ライセンス・クレジット・プライバシー

このページは Mutable Instruments Beads のファームウェア（beads/dsp/）と stmlib のソースコードを JavaScript に移植した非公式の教育用教材です。Mutable Instruments とは関係がなく、承認も受けていません。「Mutable Instruments」「Beads」は各権利者の名称です。移植部分も元のコードと同じ MIT ライセンスで配布します。

読み込んだ音声ファイルはこの端末のブラウザの中だけで処理され、どこにも送信・保存されません。このページは外部と通信しない設定（Content-Security-Policy）になっています。
